# Cielo Largo — web demo

## Abrir en local
Abre `index.html` directamente en el navegador para una vista rápida.

## Publicar en Vercel
1. Sube esta carpeta a un repositorio nuevo de GitHub.
2. En Vercel, selecciona **Add New → Project** y conecta el repositorio.
3. Framework preset: **Other**. Build command y Output Directory se dejan vacíos si Vercel detecta el sitio estático; si no, usa `.` como Output Directory.
4. Deploy.

## Antes de publicar para clientes
- Sustituir platos/precios de ejemplo por la carta aprobada.
- Confirmar teléfono, dirección y horario.
- Verificar reseñas, autoría y puntuación con el perfil oficial de Google.
- Conectar el formulario de reservas a un backend/CRM; por ahora es una demo visual y no guarda ni envía reservas.
- Añadir aviso de privacidad y consentimiento adecuados para datos personales.
- Comprobar licencias de fotografías y sustituir las provisionales por fotos autorizadas cuando sea posible.
